# AI Coaching Platform

This project is a dynamic coaching platform that offers personalized sessions across various coaching options. Using AI-powered models, it provides engaging and insightful conversations in fields like topic-based lectures, mock interviews, question-answer preparation, language learning, and mindfulness meditation.

## Features

- **Personalized Coaching:** Based on user input and selected coaching options, the platform customizes each session.
- **Real-time AI Interactions:** Seamless integration with OpenAI and other AI models for live feedback and responses.
- **Diverse Coaching Options:** Supports multiple coaching options like "Topic Base Lecture," "Mock Interview," "Ques Ans Prep," "Learn Language," and "Meditation."
- **Interactive Experts:** Users can choose from a set of expert profiles with personalized voice and avatar options.
- **Real-time Transcripts:** Sessions are logged and stored for review, allowing users to track their progress.
