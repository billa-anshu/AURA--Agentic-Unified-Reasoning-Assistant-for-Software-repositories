# WhatsApp Chat Analyzer

Transform chaotic message histories into actionable intelligence. Reveal behavioral patterns, sentiment trajectories, and semantic insights with our forensic-grade analysis engine.

## Overview
A web-based application built using Streamlit that allows users to upload exported WhatsApp chats and analyze conversation patterns using data analytics and NLP techniques. It features a premium "Forensic Stream" UI.

## Features Included
*   **Overall Conversation Intel**: Analyze total messages, total words, media shared, and links.
*   **Timeline Analysis**: Activity mapped across months and days.
*   **Activity Heatmaps**: Find out the exact days and hours where communication peaks.
*   **NLP Semantic Word Cloud**: Generate visual representation of frequent keywords.
*   **Emoji Spectrum**: Evaluates the emojis to map Laughter, Approval, and Surprise.
*   **Sentiment Velocity Baseline**: Powered by VADER, extracts the average positivity or negativity of messages over time.
