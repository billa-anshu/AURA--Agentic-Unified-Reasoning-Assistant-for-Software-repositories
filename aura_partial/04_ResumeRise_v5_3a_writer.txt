## 1. Overall purpose and architecture

ResumeRise is a web application designed to assist job candidates by providing AI-driven resume matching and mock interview simulations. The platform addresses the need for personalized feedback on application materials and interview performance, serving users who require preparation tools for technical and behavioral interviews. The technology stack consists of a Python backend built with FastAPI and a JavaScript frontend utilizing React and Tailwind CSS. The backend leverages the Groq library for AI processing and PyPDF2 for document parsing, while the frontend manages user interactions and real-time media capture.

The architecture follows a Model-View-Controller (MVC) pattern, strictly separating the user interface from the business logic. The frontend acts as the View layer, handling data collection and user input validation, such as ensuring uploaded files are valid PDFs before processing [C6]. The backend serves as the Controller and Model layer, implemented via the FastAPI framework, which is instantiated with the title "ResumeRise API" and configured with middleware to handle cross-origin requests [C12]. The backend establishes a Request-Response pattern where endpoints process structured input and return processed results, adhering to RESTful conventions [C16]. For example, the `generate_final_feedback` endpoint validates that the `responses` list is not empty and raises an HTTP 400 exception if no data is provided [C15, C16]. The repository is organized into distinct `backend` and `frontend` directories, with the backend containing core API logic and the frontend housing the React application structure, including pages for Home, Resume Match, and Mock Interview [C7].

## 2. Key components/modules

*   **Backend API (`backend/main.py`)**: This module serves as the central entry point for all HTTP requests, initializing the FastAPI application and adding middleware for cross-origin resource sharing [C12]. It initializes the Groq API client using an environment variable for the API key, enabling AI-driven analysis of resume and job description data [C13]. The `match_resume_ml` endpoint accepts a PDF resume and job description, extracting text using PyPDF2 to prepare data for skill matching [C1]. The `generate_final_feedback` function aggregates data by calculating total and average scores from provided responses and constructs a transcript string by enumerating questions and answers [C16].
*   **Resume Matching Interface (`frontend/src/pages/ResumeMatchPage.jsx`)**: This component manages the user input for the resume matching feature. The `handleFileChange` function validates that the uploaded file is a valid PDF, setting the file state if correct or displaying an error otherwise [C6]. Visual feedback is provided through utility functions like `getScoreColor`, which returns specific text color classes based on numerical scores, and `getScoreBg`, which determines border and background color classes for score indicators [C10, C11].
*   **Mock Interview Interface (`frontend/src/pages/MockInterviewPage.jsx`)**: This module handles the real-time mock interview experience. The `initCamera` function requests media permissions and binds the video stream to a DOM element to prepare the interface for real-time processing [C17]. The `loadInterviewConfig` hook retrieves interview configuration and questions from location state or sessionStorage to initialize the environment [C3]. The `generateNextQuestion` function updates the conversation state by appending objects that capture the question, transcription, detected emotion, score, and feedback [C18]. The `stopCapturingFrames` function halts the video frame capture process by clearing the interval reference to manage browser resources [C14]. The `getEmotionColor` function maps detected emotional states to Tailwind CSS color classes for visual representation [C9].
*   **Interview Setup and Review (`frontend/src/pages/InterviewSetupPage.jsx`, `frontend/src/pages/InterviewReviewPage.jsx`)**: The setup page uses `handleStartInterview` to validate that a resume file and job description are provided before constructing a FormData object to initiate the process [C5]. The `handleInputChange` function updates input field states and clears existing error messages as the user types [C8]. The review page utilizes `generateFinalReport` to compile user responses, transcriptions, feedback, scores, and emotional data into a payload for the final interview report [C2].
*   **Application Routing (`frontend/src/App.js`)**: This component defines the main routing structure, mapping specific URLs to pages such as Home, Resume Match, and Mock Interview to ensure navigation between functional modules [C7].
*   **Homepage (`frontend/src/pages/HomePage.jsx`)**: This module includes the `handleScroll` event listener, which monitors the window's scroll position to update the header's styling when the user scrolls more than 50 pixels [C4].
