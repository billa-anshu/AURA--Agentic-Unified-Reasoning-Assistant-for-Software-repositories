Based on the provided README, the project is a full-stack web application that combines a symptom-based disease prediction tool with a conversational chatbot powered by machine learning models. The system utilizes a Support Vector Classifier (SVC) model to predict potential diseases based on user-selected symptoms, offering detailed information such as descriptions, precautions, medications, and diet recommendations. Additionally, it employs a fine-tuned DistilGPT2 model to handle natural language interactions and provide preliminary insights into diseases, symptoms, and treatments. The backend API is built with Flask to manage routing, model interaction, and data processing, while the user interface is designed to be simple and intuitive for symptom selection and query input.
