Based on the provided background information, the project is a full-stack web application that serves as a health assistant, combining a symptom-based disease prediction tool with a conversational chatbot powered by machine learning models.

The system features a **Symptom-Based Disease Prediction** component that utilizes a Support Vector Classifier (SVC) model trained on a symptom dataset to predict potential diseases based on user-selected symptoms. This component provides detailed information on predicted conditions, including descriptions, precautions, medications, and diet recommendations.

Additionally, the application includes a **Conversational Chatbot** that employs a fine-tuned DistilGPT2 model for natural language interaction. This chatbot responds to user queries by offering preliminary insights into potential diseases, symptoms, and treatments based on text input.

The user experience is supported by a **User-Friendly Interface** designed for simple and intuitive symptom selection and query input, with a clear display of predictions, details, and chatbot responses. The **Backend API** is built with Flask, which handles routing, model interaction, and data processing.
